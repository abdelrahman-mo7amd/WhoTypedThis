# 🎭 Who Typed This?

> A real-time multiplayer typing & guessing game where friends compete, lie, and accidentally expose their typing personalities.

🌐 Live Demo: [WhoTypedThis Game](https://whotypedthis-f9704.web.app/?utm_source=chatgpt.com)

## ✨ Overview

**Who Typed This?** is a real-time multiplayer web game built with Firebase where players join rooms, send hidden inputs, and try to guess who typed what.

It’s fast, chaotic, and designed to turn every group of friends into professional bug testers and liars.

---

## 🚀 Features

* ⚡ Real-time multiplayer synchronization
* 🔐 Firebase Authentication support

* 💬 Live typing & guessing mechanics

## 🎮 How to Play

1. Open the game
2. Create or join a room
3. Wait for players
4. Start the round
5. Each player submits input
6. Everyone guesses “who typed this”
7. Points are calculated based on accuracy

---

## 🔐 Security Rules

Firestore rules are enforced to:

* Prevent unauthorized writes
* Restrict room manipulation
* Protect game state integrity

---

## 🧠 Architecture

* Firestore acts as the **real-time sync engine**
* Each room is a document
* Players are sub-collections / fields
* `onSnapshot()` handles live updates instantly
